LiMA 原選

LiMA 原選

送一份禮，傳遞一段故事。

LiMA 取自南島語族的「手」與「五」，代表著掌心的承擔與創作的溫暖。我們匯集全台部落職人與小農的心意，讓每一份禮物，都成為貼近生活的永續美好。

品牌理念

「LiMA 原選」不僅是一個品牌，更是連結台灣原鄉文化與現代生活的橋樑。我們相信，優質的原鄉產業不需要同情性消費，而是需要站上對的舞台，用商品品質與文化底蘊深深打動人心。

VALUE 01

🧵 精緻工藝與文創美學

傳承世代織布、陶藝與木雕技藝，融入生活實用設計。

VALUE 02

🌾 友善土地與在地風味

嚴選友善耕作的特有作物與高山茶咖啡，品嚐最純粹的土地風土。

VALUE 03

🌏 ESG 永續價值與責任

支持在地部落職人與友善農作，讓您的每一次消費，都為台灣產業永續盡一份力。
